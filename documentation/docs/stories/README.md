# Registro de stories

Aquí se guarda copia de cada story refinada con skill `story`, en estado aprobado.

## Convención

- Un archivo por story: `documentation/docs/stories/<tarea>-<slug>.md`.
- Usar número tarea Kanban en `PROJECT_CONTEXT.md`.
- Mantener formato: Story, Acceptance criteria, Plan, Out of scope, Suggestions.
- Agregar estado y fecha arriba.
- No guardar propuestas rechazadas, código ni detalles fuera plan.

## Estados

- `Propuesta`: todavía no aprobada.
- `Aprobada`: lista para implementar con `pair`.
- `Implementada`: código y validación terminados.
- `Descartada`: reemplazada por otra story.
